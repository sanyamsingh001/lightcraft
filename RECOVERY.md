# UNTESTED LightCraft source recovery

These branches preserve surviving source before a requested workspace reset. They are not validated changes and are not intended for merging as-is. No feature validation is claimed.

See `source-map.json` for every original metadata-index and local-branch mapping, exact recovery heads/trees, excluded private capture files and missing source objects.

Private capture code, credentials, logs, build outputs and historical runtime evidence are excluded. Deleted unstaged edits and missing evidence are not reconstructed.
